操作手冊

一般用途的財務可行性試算工具，不是特定店家的企劃書。用來評估「這個餐飲業態、在這個租金與坪數條件下，撐不撐得住」，數字全部是可調整的起始值。

操作步驟

  1. 頁面上方是互動平面圖：拖動「調整經營假設」裡的滑桿，即時看坪數怎麼分配、算出幾個座位、月營收多少
  2. 平面圖右側「每月顧客人次（內用）」卡片會即時算出這個座位數與翻桌率組合下，每月大約服務多少內用來客量（外帶／外送不計入人次，只反映在營收占比上）
  3. 先點一個貼近你規劃的餐飲業態範例按鈕（火鍋／燒肉／日式定食／餐酒館／早午餐／熱炒合菜），會套用該業態對應的定價、翻桌率、成本結構與人事編制假設；之後可以再自行微調任何一個滑桿
  4. 五組變數分類（空間與坪效／定價與翻桌率／成本結構佔比／人事編制／CAPEX與押金）之間沒有先後順序，可以任意切換調整
  5. 下方「本月損益試算票根」會即時重算，綠字代表落在建議健康區間、紅字代表超出建議範圍
  6. 想重新開始，按頁尾「重設為基準假設」會清掉所有調整，回到中性起始值（不對應任何一個業態）
每客席坪數是套用在「總坪數扣掉廚房、動線／廁所之後」剩下的內用坪數，不是總坪數——平面圖下方的算式會即時印出完整換算過程。
每月顧客人次＝座位數 ×（平日翻桌次數 × 平日營業天數 ＋ 假日翻桌次數 × 假日營業天數），只計內用來客量；這個數字跟月營收共用同一組翻桌率與座位數假設，兩者連動。

已儲存的方案

調整好的變數可以存成一筆具名紀錄，方便之後比較不同方案（例如同一個業態的保守版跟積極版），不需要每次都重新調整一次滑桿。

  1. 在「已儲存的方案」區塊輸入一個名稱（留白會用目前套用的業態範例名稱，若沒套用業態範例則用「未命名方案」），按「💾 儲存目前方案」，就會存成一筆新紀錄
  2. 用同樣名稱再存一次會詢問是否要覆蓋既有紀錄
  3. 清單中每一筆可以「載入」（覆蓋回目前所有變數，會先詢問確認）、「重新命名」或「刪除」（皆無法復原）
儲存的方案只存在這台瀏覽器的 localStorage，換一台電腦或清除瀏覽器資料就會不見；沒有下載備份功能，重要方案建議另外用「匯出 PDF」存一份檔案。

請 AI 診斷目前的方案

沒有 API 金鑰也能用：直接按「改用規則式健檢」，會依目前哪些成本比例超出建議範圍，組出對應的健檢建議，不需要連網。

想要更貼近你情境的診斷，可以展開「AI 診斷設定」，選擇服務商（Claude／OpenAI／Gemini／OpenRouter）並填入你自己的 API 金鑰，按「請 AI 診斷目前的方案」。

診斷區塊上方有 5 個「診斷角度」快速按鈕，點選後會把對應的提示文字帶入下方文字框，作為請 AI 特別關注的方向：

  • 整體健檢：逐一檢查所有成本占比，條列優先處理項目
  • 坪效與選址適配度：評估這個業態在目前租金／坪數下是否選對地方
  • 成本優化排序：只看超標項目，依對淨利的影響金額排序給建議
  • 貸款／募資簡報用語：改寫成適合放進銀行貸款申請書或投資人簡報的正式語氣
  • 悲觀情境壓力測試：假設營收只剩 70%，評估撐多久、哪個成本先出問題
文字框內容可以自行編輯或清空，不一定要用按鈕帶入的範本；這個欄位只影響 AI 診斷，不影響規則式健檢。AI 呼叫失敗時（例如金鑰無效）會自動退回規則式健檢，不會沒有內容。

匯出 PDF

頁面右上角按「📄 匯出 PDF」，會開啟瀏覽器的列印視窗，選「另存為 PDF」即可把目前的試算內容存成 PDF 檔。匯出時會自動：

  • 把五組變數分類全部展開成一份完整報告（畫面上一次只會顯示一組，匯出時會全部列出）
  • 隱藏滑桿、按鈕、AI 金鑰欄位等互動元件，只保留數字與說明文字
  • 加上「僅供試算參考・非正式財務報表」的浮水印，以及產生時間戳記，提醒這份輸出是估算工具的結果，不是正式財務報表
如果曾經產生過 AI 診斷結果，該段診斷文字也會一起出現在匯出的 PDF 裡；沒有產生過就不會出現這個區塊。

加入主畫面（可選）

頁尾按「📲 加入主畫面」，可以把這個工具像 App 一樣安裝到手機或電腦桌面，之後不用開瀏覽器輸網址就能直接點圖示開啟。

  • Android（Chrome）／桌面 Chrome、Edge：按下按鈕會直接跳出安裝確認視窗
  • iPhone／iPad（Safari）：按下按鈕會提示改用「分享」圖示 → 「加入主畫面」（iOS 系統限制，無法由網頁直接跳出安裝視窗）
  • Mac 桌面版 Safari：會提示改用選單列「檔案」→「加入 Dock」（Safari 17 以上）
安裝與否不影響任何功能，純粹是操作方便性；不安裝、直接用瀏覽器開網址一樣可以完整使用。

隱私說明

  • 你調整的所有變數與 AI 診斷內容，都只存在自己瀏覽器的 localStorage，關閉分頁後下次打開仍會保留，但不會傳送到任何伺服器
  • AI 金鑰同樣只存在瀏覽器的 localStorage；按下「請 AI 診斷」且有填金鑰時，你的試算資料會直接連線送到你選擇的服務商官方 API，不會經過本工具作者或任何第三方伺服器
  • 「重設為基準假設」會清除瀏覽器裡目前的變數設定與已選取的業態範例，但不會動到「已儲存的方案」清單；清單裡的「刪除」動作才會、且無法復原

使用警語

請注意：
  • 本工具的試算結果皆為估計值，不是正式財務報表，也不是專業財務、稅務或法律意見，不能取代會計師、財務顧問或實地商圈訪查
  • 業態範例（火鍋／燒肉／日式定食／餐酒館／早午餐／熱炒合菜）的預設假設為一般性參考，不代表任何真實店家的實際數字
  • 只有你主動填入 API 金鑰並按下「請 AI 診斷」時才會呼叫語言模型，不使用這項功能就完全不會連網；請勿在任何欄位輸入真實個資或公司機密
  • AI 生成的診斷內容可能包含錯誤或不合時宜的建議，實際決策前務必自行檢查與查證
  • 使用 AI 診斷功能所產生的 API 費用由你與所選服務商的方案自行負擔，本工具不會向你收費
  • 本工具與創作者不對依據本工具試算結果或 AI 診斷內容所做之任何經營決策負責
