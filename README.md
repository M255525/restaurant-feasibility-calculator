# 餐飲店經營評估試算工具

一般用途的餐飲店經營財務可行性試算工具，不是特定店家的企劃書。以台北／新北一線商圈中高固定成本結構為情境，把「坪數配置 → 座位數 → 營收 → 成本 → 淨利」整條推算鏈拆成可調整的變數，即時試算損益並依健康帶判色。

🔗 線上使用：<https://m255525.github.io/restaurant-feasibility-calculator/>

- 純前端單頁網站，無需安裝、無後端、無序號授權。
- 互動平面圖：拖動滑桿即時看廚房／動線／內用怎麼分這塊地、排出幾個座位、算出多少營收。
- 6 組餐飲業態快速範例（火鍋／燒肉／日式定食／餐酒館／早午餐／熱炒合菜），各自套用對應的定價、翻桌率、成本結構與人事編制假設。
- 損益試算票根即時重算，綠字＝落在建議健康區間、紅字＝超出建議範圍。
- 選填 Claude／OpenAI／Gemini／OpenRouter 的 API 金鑰（BYOK，只存瀏覽器 localStorage），可請 AI 依 5 種診斷角度（整體健檢／坪效與選址適配度／成本優化排序／貸款募資簡報用語／悲觀情境壓力測試）生成診斷；沒有金鑰或呼叫失敗會自動退回規則式健檢。
- 可匯出 PDF（含「僅供試算參考」浮水印），也可「加入主畫面」安裝成 App；完整操作說明見 [`manual.html`](./manual.html)。
